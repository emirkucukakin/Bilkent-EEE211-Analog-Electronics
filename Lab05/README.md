# Lab 05 — Tuned RF Transmitter Amplifier

**EEE211: Analog Electronics — Bilkent University, Fall 2026**

**Author:** Emir Küçükakın

## Overview

This experiment examines the 27.002 MHz transmitter amplifier on the TRC-11 board. The circuit uses a 2N2222 transistor and a tuned output transformer, while a separate transistor stage controls the amplifier supply voltage.

## Contents

The laboratory report documents the tuned output network and the supply modulation circuit. It also compares the second and third harmonics at two input amplitudes using the oscilloscope’s FFT function.
